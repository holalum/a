# Aurora VPN — Telegram Mini App

Фронтенд Telegram Mini App для VPN-сервиса: управление подпиской, устройствами,
профилем, тарифами и колесо фортуны с еженедельным бесплатным спином.

Сейчас весь бэкенд — заглушки. Позже подключается панель **Remnawave**.

## Стек

- React 18 + TypeScript
- Vite
- Telegram WebApp SDK (тема, haptic feedback, BackButton)
- Без UI-зависимостей — кастомный CSS

## Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

Приложение работает и в обычном браузере (Telegram SDK мягко деградирует), и
внутри Telegram. Для теста как Mini App: опубликовать `dist/` по HTTPS и указать
URL в @BotFather → Bot Settings → Menu Button / Web App.

## Структура

```
src/
  api/
    types.ts      доменные типы (Profile, Subscription, Device, Plan, Prize…)
    mock.ts       заглушечный «бэкенд» с задержками и состоянием в памяти
    index.ts      единая точка входа в API
    wheel.ts      призы, взвешенный рандом, недельный кулдаун (localStorage)
  components/     BottomNav, иконки, переиспользуемый UI
  pages/          Home, Devices, Wheel, Plans, Profile
  store.tsx       глобальное состояние (React Context)
  toast.tsx       всплывающие уведомления
  telegram.ts     обёртка над Telegram WebApp SDK
```

## Экраны

- **Главная** — статус подписки, остаток дней и трафика, копирование ключа,
  быстрые локации, статистика.
- **Устройства** — список устройств, переименование, отключение.
- **Колесо** — колесо фортуны на `<canvas>`, спин раз в 7 дней, история призов.
- **Тарифы** — список планов, оформление в демо-режиме.
- **Профиль** — аккаунт, реферальная программа, автопродление, поддержка.

## Колесо фортуны

- 8 секторов, взвешенный рандом (`pickPrize` в `api/wheel.ts`).
- Призы: дни подписки, бонусный трафик, скидки, джекпот «30 дней».
- Кулдаун — 7 дней, время последнего спина и история хранятся в `localStorage`.
- Анимация — плавное затухание (`easeOutCubic`) + haptic-тик на границах секторов.

> Когда логика спина переедет на сервер, проверку кулдауна и розыгрыш приза
> нужно делать на бэкенде — клиентскую проверку можно обойти.

## Подключение Remnawave

Заменить `api/mock.ts` на реальный клиент с тем же интерфейсом `Api`
и переключить экспорт в `api/index.ts`. Остальной код менять не нужно —
страницы и стор работают только через этот интерфейс.
